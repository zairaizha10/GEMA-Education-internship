# 🌟 Student Portfolio Website

A modern and responsive student portfolio website built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- 🎨 Modern UI Design
- 🌙 Dark Mode Toggle
- ⌨️ Typing Animation
- 📊 Animated Statistics Counters
- 🖼️ Project Showcase
- 🏆 Certificate Gallery
- 📱 Fully Responsive Design
- 📧 Contact Form Validation
- ✨ Smooth Scroll Animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- AOS Animation Library

## 📂 Sections

- Home
- About Me
- Academic Performance
- Skills
- Achievements
- Projects
- Certificates
- Blog
- Testimonials
- Contact

## 🎯 Purpose

This portfolio showcases a student's academic achievements, technical skills, projects, and extracurricular activities in an engaging and professional manner.

## 📸 Preview

A clean, interactive, and mobile-friendly portfolio designed to create a strong first impression.
